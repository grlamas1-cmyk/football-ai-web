Las cuotas se autocompletan con el comparador cuando están disponibles. Puedes sobrescribirlas a mano — el modelo "Con cuotas" las necesita para predecir (el modelo "Sin cuotas" no las usa, pero igualmente hacen falta para calcular el valor de la apuesta).
Mercados de goles (opcional)
Estas cuotas son opcionales. Si las rellenas, ayudan al modelo a afinar el 1X2 (usa el mercado de goles como señal extra). Debajo del resultado verás además la probabilidad de más/menos de 2.5 goles y de que marquen los dos equipos, calculada directamente con el modelo de goles esperados (Poisson) — no hace falta rellenar nada para verla.
"Sin cuotas" es un modelo entrenado desde cero SIN ninguna de las variables de mercado (ni las cuotas, ni nada derivado de ellas) — pensado para comparar contra la casa de apuestas sin usar su propia información. Es normal que acierte algo menos que "Con cuotas": el mercado sí contiene información real, y este modelo renuncia a ella a propósito. Accuracy/log loss de referencia: con cuotas 54.9% / 0.946 — sin cuotas 52.8% / 0.977 (mismo test, ver metadata.json).
